Mirror Hub（crproxy）

自托管容器镜像加速入口，聚合 Docker Hub / GHCR / Quay.io 等多源镜像。

快速启动

docker compose up -d

启动后：
- 镜像代理：http://<your-host>:5000
- 文档与状态页：http://<your-host>:8080

查看服务状态页

多源镜像代理配置

默认映射定义在 config/registrymap.json：

{
  "default": "https://registry-1.docker.io",
  "docker": "https://registry-1.docker.io",
  "ghcr": "https://ghcr.io",
  "quay": "https://quay.io"
}

Docker 使用示例

{
  "registry-mirrors": ["http://<your-host>:5000"],
  "insecure-registries": ["<your-host>:5000"]
}

配置文件：/etc/docker/daemon.json，修改后重启 Docker。

containerd 使用示例

在 /etc/containerd/certs.d/docker.io/hosts.toml 中配置：

server = "https://registry-1.docker.io"

[host."http://<your-host>:5000"]
  capabilities = ["pull", "resolve"]
  skip_verify = true

修改后执行 systemctl restart containerd。
